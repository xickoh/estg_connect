# 🌐 Website de Divulgação — Seminário Tecnológico

Bem-vindo ao repositório oficial do **Website de Divulgação do Seminário Tecnológico**, um projeto desenvolvido pela **Equipa Técnica**, integrada na **Equipa de Comunicação e Divulgação**.  
O objetivo deste website é proporcionar uma plataforma moderna, acessível e informativa para promover o seminário, facilitar o acesso a conteúdos relevantes e reforçar a presença digital do evento.

---

## 🚀 Objetivos do Projeto

- Criar um website responsivo, rápido e visualmente apelativo.  
- Centralizar toda a informação sobre o seminário: programa, oradores, inscrições e contactos.  
- Reforçar a estratégia de comunicação e divulgação do evento.  
- Garantir uma experiência de navegação simples e intuitiva para todos os utilizadores.

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript
- **Frameworks / Bibliotecas:** Typescript, React
- **Backend:** C#, SQL
- **Outras Ferramentas:** Git, Figma
